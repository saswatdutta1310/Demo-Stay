# Client Onboarding Form & Checklist

Send this checklist to hoteliers and guest house owners to gather all information needed to launch their custom demo in 10 minutes:

### 1. Basic Details
- [ ] Property Name:
- [ ] Tagline / Short description:
- [ ] Contact Phone / WhatsApp number for bookings:
- [ ] Official Email:
- [ ] Physical Address & Google Maps link:

### 2. Room Categories & Pricing
For each room category:
- [ ] Room Name (e.g. Deluxe AC, Family Suite)
- [ ] Base price per night (₹)
- [ ] Maximum guest capacity (Adults + Children)
- [ ] Bed type (King / Queen / Twin)
- [ ] Key amenities (AC, Wi-Fi, Geyser, TV, Breakfast)
- [ ] Total number of units

### 3. Media & Photos
- [ ] Property logo (SVG or high-res PNG)
- [ ] 1 Hero cover photo (horizontal, bright)
- [ ] 3-5 photos per room type
- [ ] 3-5 photos of property facade, reception, and dining

### 4. Policies
- [ ] Check-in and check-out times (Standard: 12 PM check-in / 11 AM check-out)
- [ ] Cancellation terms (48h free cancellation / non-refundable)
- [ ] Accepted Photo IDs
